# آکادمی HSE — پلتفرم آموزشی ایمنی، بهداشت و محیط زیست

پلتفرم آموزشی B2C برای برگزاری دوره‌های تخصصی HSE: فروش دوره، برگزاری کلاس آنلاین
و آفلاین، آزمون، صدور گواهی و استعلام عمومی گواهی.

| موضوع | فناوری |
|---|---|
| زبان | Python 3.12 |
| فریم‌ورک | Django 5.2 LTS |
| قالب | Django Templates + Bootstrap 5 (محلی) |
| دیتابیس توسعه | SQLite |
| دیتابیس Production | PostgreSQL |
| سرور Production | Ubuntu + Gunicorn + Nginx |

> **وضعیت فعلی: فاز ۱ — راه‌اندازی پروژه.**
> نقشه راه کامل: [`docs/roadmap.md`](docs/roadmap.md) · معماری و دیتابیس: [`docs/architecture.md`](docs/architecture.md)

## راه‌اندازی پروژه روی سیستم شما

پیش‌نیاز: **Python 3.12** و **Git** نصب باشند. برای بررسی:

```bash
python --version
git --version
```

### ۱. دریافت پروژه

```bash
git clone <آدرس-مخزن>
cd HSE-academy
```

### ۲. ساخت محیط مجازی (Virtual Environment)

محیط مجازی یک پوشه جداست که کتابخانه‌های این پروژه فقط داخل آن نصب می‌شوند و با
سایر پروژه‌های سیستم شما تداخل پیدا نمی‌کنند.

**ویندوز:**

```bat
python -m venv .venv
.venv\Scripts\activate
```

**لینوکس / مک:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

بعد از فعال شدن، ابتدای خط ترمینال عبارت `(.venv)` را می‌بینید. **تا وقتی این را
نمی‌بینید، دستورهای بعدی را اجرا نکنید.**

### ۳. نصب کتابخانه‌ها

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### ۴. ساخت فایل تنظیمات `.env`

**ویندوز:**

```bat
copy .env.example .env
```

**لینوکس / مک:**

```bash
cp .env.example .env
```

فایل `.env` رمزها و کلیدهای شماست و **هرگز داخل گیت ذخیره نمی‌شود**. برای شروعِ
توسعه، مقادیر پیش‌فرض کافی است و نیازی به تغییر ندارند.

### ۵. ساخت جدول‌های دیتابیس

```bash
python manage.py migrate
```

### ۶. ساخت کاربر مدیر

نام کاربری سایت **شماره موبایل** است، نه username.

```bash
python manage.py createsuperuser
```

### ۷. اجرای سرور

```bash
python manage.py runserver
```

حالا در مرورگر باز کنید:

- سایت: <http://127.0.0.1:8000/>
- پنل مدیریت: <http://127.0.0.1:8000/admin/>
- بررسی سلامت: <http://127.0.0.1:8000/health/>

برای خاموش کردن سرور، در ترمینال `Ctrl + C` بزنید.

## نکات مهم

**فایل `.env` را در گیت قرار ندهید.** این فایل در `.gitignore` هست. اگر کلیدی به
اشتباه commit شد، باید آن کلید را باطل و کلید جدید بسازید.

**وابستگی به اینترنت خارجی:** تمام فایل‌های CSS، JS، فونت و آیکون به‌صورت محلی در
پوشه `static/` نگهداری می‌شوند. از Google Fonts یا CDN خارجی استفاده نمی‌کنیم تا
سایت در زمان اختلال اینترنت بین‌الملل هم کامل بالا بیاید.

**سرویس‌های خارجی در حالت Mock:** پیامک، استعلام هویت و پرداخت در محیط توسعه
شبیه‌سازی شده‌اند (`USE_MOCK_SMS`، `USE_MOCK_IDENTITY`، `USE_MOCK_PAYMENT` در فایل
`.env`). یعنی می‌توانید کل جریان ثبت‌نام تا خرید را بدون خرید هیچ سرویسی تست کنید.

## تنظیم VS Code

فایل `.vscode/settings.json` از قبل آماده است. فقط یک نکته برای **ویندوز**: مسیر
مفسر پایتون را به این تغییر دهید:

```json
"python.defaultInterpreterPath": "${workspaceFolder}\\.venv\\Scripts\\python.exe"
```

یا ساده‌تر: `Ctrl+Shift+P` → `Python: Select Interpreter` → گزینه‌ای که داخل آن
`.venv` نوشته شده را انتخاب کنید.
